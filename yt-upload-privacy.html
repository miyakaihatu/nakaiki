yt-upload プライバシーポリシー

最終更新：2026年11月17日

「yt-upload」は、運営者が自分の YouTube チャンネルに動画を上げ、自分のチャンネルの再生数などを確認するためだけに使う個人用のツールです。一般の方に向けたサービスではありません。

使う情報

Google アカウントで許可したときに、YouTube Data API と YouTube Analytics API を通じて、許可したチャンネルへの動画のアップロードと、そのチャンネルの情報・数字の読み取りだけを行います。

保存と共有

許可の情報（トークン）は運営者のパソコンの中だけに保存します。取得した情報を第三者に渡したり、販売したり、広告に使ったりすることはありません。

許可の取り消し

Google アカウントの「サードパーティのアプリとサービス」（https://myaccount.google.com/connections）から、いつでも許可を取り消せます。

Google API の利用について

Google API から受け取った情報の使い方は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

yt-upload Privacy Policy

Last updated: November 17, 2026

"yt-upload" is a personal tool used only by its operator to upload videos to the operator's own YouTube channels and to read those channels' statistics. It is not offered to the public.

With the permission granted through a Google account, it uses the YouTube Data API and YouTube Analytics API only to upload videos to, and read information and statistics of, the authorized channel. Authorization tokens are stored only on the operator's own computer. No data is shared with, sold to, or used for advertising by any third party. Access can be revoked at any time at https://myaccount.google.com/connections.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
